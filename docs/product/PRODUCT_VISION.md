# Product Vision

## Product

Street Concept Designer is a professional but approachable desktop environment for rapidly creating and communicating street, road-access, and intersection concepts on real-world context.

## Primary users

- traffic engineers;
- transport planners;
- TIA consultants;
- road-safety and access-design practitioners.

## Core problem

Existing options force a poor trade-off:

- simple tools are fast but lack plan-view engineering semantics;
- CAD/highway-design tools are powerful but heavy for early concept iteration;
- 3D visualization tools may communicate well but do not preserve traffic-engineering structure;
- generic graphics tools require manual drafting and specialist visual skills.

The product should remove that trade-off.

## Core proposition

A user should be able to start from map/satellite/site-plan context, describe or construct the engineering intent, adjust exact dimensions, and immediately obtain coherent 2D and 3D representations without manually drawing every lane, marking, sign, tree, or 3D object.

## Product principles

- map-first;
- 2D engineering authoring, live synchronized 3D understanding;
- direct manipulation plus exact numeric editing;
- automation-first with explicit manual override;
- progressive disclosure rather than CAD toolbar overload;
- Existing/Alternative scenarios as first-class workflow;
- engineering layer separate from presentation layer;
- Thailand/LHT default with standards-neutral architecture;
- AI-assisted authoring through deterministic commands;
- concept-design depth without detailed-design scope creep.

## Initial non-goals

- construction drawings;
- full vertical alignment and grading;
- cut/fill and earthworks;
- drainage design;
- BIM authoring;
- traffic microsimulation;
- signal optimization;
- full swept-path engineering;
- cloud collaboration;
- mobile-first editing.
