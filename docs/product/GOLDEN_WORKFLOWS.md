# Golden Workflows

These workflows drive product architecture and acceptance. Features that do not help at least one workflow need explicit justification.

## GW-01 Project access improvement — primary acceptance workflow

1. Start a project from satellite/map/site plan.
2. Establish scale/location.
3. Trace or draw the main road alignment.
4. Apply a divided-road cross-section preset.
5. Add a project access/driveway.
6. Add a right-turn pocket using taper + storage parameters.
7. Add or edit a median opening.
8. Generate relevant road markings.
9. Inspect the same design in synchronized 3D.
10. Duplicate to Alternative B and modify geometry.
11. Compare Existing / A / B.
12. Export a clear plan and 3D view.

## GW-02 Intersection improvement

Trace/create a T or four-leg junction, confirm topology, adjust per-corner geometry, add lane movements, turn pockets, islands, stop lines, and crossings, then compare alternatives.

## GW-03 Road widening

Convert an existing 4-lane concept to a 6-lane alternative with median/shoulder/sidewalk transitions while preserving station-based geometry and visualizing footprint changes.

## GW-04 Median opening / U-turn concept

Create a divided road, add median opening/U-turn treatment, configure storage/taper and markings, then inspect geometry and presentation views.

## GW-05 Urban street concept

Compose traffic lanes, parking, bicycle facility, sidewalk/verge, trees, lighting, and basic street furniture with synchronized plan/cross-section/3D views.

## GW-06 Presentation

Prepare saved plan/perspective views, selectively dim basemap/context, switch engineering/presentation display, and export Existing vs Proposed alternatives.
