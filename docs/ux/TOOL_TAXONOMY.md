# Tool Taxonomy

The UI should expose a small set of tool families and contextual actions rather than a CAD-style wall of icons.

## Navigation
- Select
- Hand / Pan
- Zoom
- Fit View / Fit Selection
- Measure

## Reference / Map
- Set Location
- Map / Satellite provider
- Import Image / Site Plan
- Scale Calibration
- Opacity / Dim / Saturation
- Georeference / CRS (advanced)

## Alignment
- Draw Road
- Line
- Circular Arc
- Smooth Conceptual Curve
- Insert Node
- Remove Node
- Split
- Join
- Simplify / Clean Geometry (later)

## Road / Cross Section
- Apply Preset
- Open Cross-Section Editor
- Add Component
- Remove Component
- Reorder Component
- Edit Width / Type / Direction

## Longitudinal
- Width Transition
- Lane Add
- Lane Drop
- Turn Pocket
- Road Widening
- Component Start / End Station

## Median / Roadside
- Raised / Flush Median
- Median Opening
- Shoulder
- Curb / Gutter
- Verge
- Sidewalk
- Bicycle Facility
- Parking
- Barrier

## Junction / Access
- Create / Confirm Junction
- Per-Corner Edit
- Lane Connections / Movements
- Island
- Crosswalk
- Stop / Yield Line
- Driveway / Project Access
- Slip Lane
- Bus Bay
- U-turn treatment
- Roundabout (later gated module)

## Markings
- Lane Line
- Edge Line
- Stop Line
- Yield Line
- Crosswalk
- Direction Arrow
- Hatch / Chevron / Gore
- Parking Stall
- Stencil / Text

## Assets
- Place Point Asset
- Place Along Path
- Place Along Edge
- Distribute In Area
- Bake / Explode Distribution
- Asset Properties / Replace

## Scenarios
- Duplicate Scenario
- Rename
- Compare Overlay
- Side-by-Side
- Before/After
- Change Summary (later)

## Inspection
- Properties
- Dimensions
- Issues / Validation
- Object Hierarchy / Layers
- Command History

## AI Copilot
- Describe Change
- Explain Selection
- Generate Alternative
- Fix Selected Issue (proposal only)

AI operations must always resolve to the same typed command layer used by manual UI.
